# NetRing IP Scanner releases

Signed builds of **NetRing IP Scanner**, a free Windows network scanner from NetRing Tech Services, LLC:
one self-contained `.exe`, no installation, no admin rights.

- Each release has `NetRingIPScanner-X.Y.Z.exe` and `SHA256.txt`.
- The exe is signed by **Netring Tech Services, LLC.** (Microsoft Artifact Signing). Right-click it, then
  Properties > Digital Signatures to check.
- Check the download: `Get-FileHash .\NetRingIPScanner-X.Y.Z.exe -Algorithm SHA256` and compare with `SHA256.txt`.

More free tools: https://www.netringtech.com
